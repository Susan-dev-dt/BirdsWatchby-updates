# 见鸟如面 · 游戏更新

此仓库用于独立启动器下载游戏更新。开发工程保存在私密仓库中。

## 更新方式

使用完整安装包中的「见鸟如面启动器」，点击「检查更新」，确认后下载需要更新的内容。支持从受支持的旧版本直接升级至最新版本，存档和照片保留。

## 发布内容

本仓库只存放加密运行对象（`.enc`）、签名版本清单、用途说明及验证公钥，不提供开发工程、明文源码或明文运行包。请勿下载 GitHub 自动生成的源码压缩包作为游戏安装包。

正式更新从已经合并至 `main` 的版本构建并验收；先上传加密对象和版本清单，最后切换最新版本清单。尚未发布首个正式更新时，启动器不会提供更新下载。
